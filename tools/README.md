# 영상 등록하는 법

유튜브 영상 하나를 받아쓰기 목록에 넣는 방법. PC(윈도우)에서만 한다.

폰이나 클라우드에서는 안 된다. 유튜브가 집이 아닌 곳의 인터넷 주소를 막기 때문이다.
폰에서 발견한 영상은 링크만 모아뒀다가 PC에서 한꺼번에 등록한다.

---

## 처음 한 번만 하는 준비

### 1. Python 설치

https://www.python.org/downloads/ 에서 노란 **Download Python** 버튼을 누른다.

설치 화면 맨 아래 **Add python.exe to PATH** 에 반드시 체크한 뒤 Install을 누른다.
이걸 빠뜨리면 나중에 명령이 실행되지 않는다.

### 2. Git 설치

https://git-scm.com/download/win 에서 받아 설치한다. 선택지는 전부 기본값 그대로 두고 넘어간다.

### 3. 자막 받는 도구 설치

시작 메뉴에서 **명령 프롬프트**를 열고 아래를 붙여넣고 엔터.

```
pip install yt-dlp
```

### 4. 저장소 내려받기

같은 창에서 아래를 차례로 붙여넣는다.

```
cd %USERPROFILE%\Documents
git clone https://github.com/BH2513/dictation.git
```

`Documents\dictation` 폴더가 생긴다. 앞으로 여기서 작업한다.

---

## 영상 등록하기

명령 프롬프트를 열고:

```
cd %USERPROFILE%\Documents\dictation
tools\add.bat "유튜브주소" 이름
```

등록 스크립트가 올리기 전에 알아서 최신 상태로 맞추므로 `git pull` 을 따로 칠 필요는 없다.

예:

```
tools\add.bat "https://www.youtube.com/watch?v=SW2bVwdr8Zg" 병훈
```

주소는 유튜브에서 복사한 것을 그대로 붙여넣으면 된다. **따옴표는 꼭 붙인다.**

이름은 누구 목록에 넣을지다. 처음 쓰는 이름이면 그 사람 목록이 새로 만들어진다.

### 잘 되면 이렇게 나온다

```
자막을 받는 중… (en, 직접 단 자막)

제목      : Example Video Title
문장      : 84개
자막 종류 : 직접 단 자막
한국어    : 없음
목록      : 병훈

올리는 중…

올렸습니다. 1~2분 뒤 사이트에서 보입니다.
```

1~2분 뒤 https://bh2513.github.io/dictation/ 에서 보인다.

---

## 알아둘 것

**자막 종류가 "자동생성"으로 나오면** 유튜브가 기계로 받아적은 자막을 쓴 것이다.
구두점이 없어서 문장이 어중간하게 잘릴 수 있다. 연습에는 쓸 수 있지만,
문장 경계가 이상하면 앱의 편집 화면에서 고친다.

**"이 영상에는 영어 자막이 없습니다"** 라고 나오면 그 영상은 쓸 수 없다. 다른 영상을 고른다.

**한국어가 "있음"이면** 그 영상은 문장카드의 한→영 모드에서도 쓸 수 있다.

## 잘 안 될 때

| 화면에 나온 말 | 뜻과 할 일 |
| --- | --- |
| `'python'은(는) ... 인식할 수 없습니다` | Python 설치할 때 **Add python.exe to PATH** 체크를 빠뜨렸다. 다시 설치한다 |
| `'git'은(는) ... 인식할 수 없습니다` | Git이 설치되지 않았다. 준비 2번 |
| `No module named yt_dlp` 또는 `'yt-dlp'...` | 준비 3번을 안 했다 |
| 유튜브에서 영상 정보를 가져오지 못했습니다 | 인터넷 또는 주소 문제. 주소를 다시 복사해 본다 |
| 올리지 못했습니다 | 인터넷 문제다. 잠시 뒤 같은 명령을 다시 실행한다 |
| 저장소를 최신 상태로 맞추지 못했습니다 | 화면에 적힌 두 줄을 그대로 실행한 뒤 등록을 다시 한다 |

유튜브가 바뀌어서 자막을 못 받는 경우가 있다. 그때는 도구를 최신으로 올린다.

```
pip install -U yt-dlp
```

## 참고 — 다른 사용법

올리지 않고 파일만 만들어 보기:

```
tools\add.bat "주소" 이름 --no-git
```

유튜브에서 자막이 안 받아질 때, 자막 파일을 직접 주기:

```
python tools\add_video.py "주소" --profile 이름 --subs-file 자막.vtt
```

한국어 자막 파일도 같이 주려면 `--ko-subs-file 한국어자막.vtt` 를 덧붙인다.

```
data/

  videos/
    p1/
      index.json                   그 사람의 영상 목록

```

내용은 SPEC.md 4-1에 적혀 있다. 직접 고칠 일은 없다.
