# 드라마·영화 대사로 연습하기

앱의 **From your videos** 탭에 실제 드라마·영화 대사가 나오게 하는 설정입니다.

**왜 이걸 하나:** AI 가 영어를 지어내면 아무리 조여도 어색한 게 섞입니다.
실제 작가가 쓰고 배우가 말한 대사는 어색할 수가 없습니다.

**한 번 해 두면 두 달쯤 갑니다.** 매일 다섯 줄 뽑는 건 저절로 돌아갑니다.

---

## 1. 어떤 작품을 쓸까

목표가 **일상 회화**니까 작품 고르는 게 절반입니다.

### 좋은 것 — 시트콤

| 작품 | 왜 |
|---|---|
| **Friends** | 이 용도의 교과서입니다. 일상 주제, 또박또박, 대사량이 압도적. 90년대라 아주 가끔 옛말이 나오지만 95%는 지금도 씁니다 |
| **Modern Family** | 요즘 말투. 가족·직장 상황이 골고루 있고 말투 폭이 넓습니다 |
| **The Office (미국판)** | 직장 영어. 어색한 대화를 어떻게 넘기는지 배우기 좋습니다 |
| **New Girl**, **Brooklyn Nine-Nine** | 빠르고 가장 요즘 말투 |

### 피할 것

- **의학·법정·범죄물** (Grey's Anatomy, Suits, Breaking Bad) — 전문용어가 절반이고
  일상에 못 씁니다
- **판타지·시대극** (왕좌의 게임, 브리저튼) — 옛날 말투
- **사투리가 센 영국 드라마** (Peaky Blinders, Derry Girls) — 알아듣기부터 어렵습니다
- **영화 전반** — 드라마보다 나쁩니다. 대사가 적고, 극적인 대사라 일상에 안 씁니다.
  시트콤 한 편이 영화 한 편보다 쓸 만한 대사가 많습니다

### 얼마나 필요한가

**시트콤 20편쯤이면 넉넉합니다.** 한 편에 쓸 만한 대사가 50~150줄 나오고,
거기서 300줄을 뽑아 두면 하루 다섯 줄씩 두 달을 씁니다.

---

## 2. 자막을 어디서 구하나

`.srt` 파일이 필요합니다. 영어 자막이어야 합니다.

- **OpenSubtitles.org** — 제일 크고 무료입니다. 검색해서 내려받으면 됩니다
- **Language Reactor** — 넷플릭스를 보면서 자막을 뽑는 확장 프로그램입니다.
  전에 말씀하셨던 그거예요. 보고 있는 작품 자막을 그대로 쓸 수 있습니다
- **가지고 계신 파일** — 이미 자막 파일이 있으면 그대로 쓰면 됩니다

> **원본 자막 파일은 PC 에만 둡니다.** 저장소에 올라가는 건 거기서 뽑은 300줄뿐입니다.
> 교재가 문장을 인용하는 정도입니다.

---

## 3. 좋은 자막 가려내기

**눈으로 안 고르셔도 됩니다. 도구가 봐 주고, 나쁜 건 알아서 뺍니다.**
그래도 받을 때 알아두면 좋은 것:

| 이건 좋습니다 | 이건 나쁩니다 |
|---|---|
| 사람이 만든 영어 자막 | **자동 생성 자막** — 문장부호가 없어서 못 씁니다 |
| 30분 분량에 30~60KB | 몇 KB짜리 — 일부만 들어 있습니다 |
| `.srt` / `.vtt` / `.smi` / `.ass` | 한국어 자막 (영어를 연습해야 하니까요) |

**두 가지는 신경 안 쓰셔도 됩니다.**

- **싱크가 안 맞아도 됩니다.** 글자만 쓰고 시각은 안 씁니다
- **SDH / 청각장애인용도 괜찮습니다.** `[문 닫히는 소리]` 같은 건 도구가 알아서 뺍니다

---

## 4. 실행하기

### 미리 확인만 해 보기 (아무것도 안 올라감)

자막을 폴더 하나에 모아 두고, 저장소 폴더에서:

```
python tools\add_subs.py "C:\Users\bh\Desktop\자막" --dry-run
```

이렇게 나옵니다.

```
12개 자막 파일을 읽습니다.

  ✓ Friends S01E01 — 87줄
  ✓ Friends S01E02 — 94줄
  ✓ Modern Family S03E12 — 76줄

쓰지 않은 파일:
  ✗ Friends.S01E03.auto.srt
      문장부호가 거의 없습니다. 자동 생성 자막으로 보입니다 — 연습에 못 씁니다.
  ✗ Friends.S01E04.kor.srt
      한국어 자막입니다. 영어 자막을 넣어 주세요.

모두 257줄 중에서 257줄을 골랐습니다.
```

**✗ 로 나온 파일은 지우고 다른 걸 받으시면 됩니다.**

### 진짜 올리기

```
subs "C:\Users\bh\Desktop\자막" 병훈
```

(`병훈` 은 앱에서 쓰는 프로필 이름입니다.)

## 5. 그다음

내일 아침부터 앱의 **From your videos** 탭에 대사가 나옵니다.
지금 바로 보고 싶으면 GitHub 의 **Actions → 하루 다섯 문장 → Run workflow** 를 누르세요.

### 대사는 두 번 걸러집니다

1. **도구가 규칙으로** — 문장부호로 끝나고 6~30 단어인 것만. 노래 가사, 소리 설명,
   화자 이름표는 뺍니다
2. **AI 가 뜻을 보고** — 규칙은 길이밖에 못 봅니다. 후보 30개를 주고 그중
   다섯 개만 고르게 합니다. 이런 건 버립니다:
   - 앞뒤를 모르면 뜻이 안 통하는 말 (`He said he would do it.`)
   - 그 작품에서만 통하는 말 (인물 이름, 그 드라마의 사건)
   - 일상에 못 쓰는 말 (총격전, 법정)
   - **비속어·성적인 내용** — 가족이 함께 쓰는 앱이라 반드시 뺍니다
   - 배울 게 없는 뻔한 말

   다섯 개를 못 채우면 **억지로 채우지 않습니다.**

### 새 작품을 넣고 싶으면

같은 명령을 다시 돌리면 됩니다. **전에 올린 것은 새 것으로 바뀝니다.**
계속 쌓고 싶으면 자막 폴더에 파일을 더 넣은 채로 돌리세요.

### 자막이 떨어지면

300줄이면 두 달입니다. 다 쓰면 같은 대사가 다시 나오기 시작하니,
그때 자막을 더 넣고 명령을 한 번 더 돌리시면 됩니다.
